# 服务管理模块设计

日期：2026-08-25  
状态：已批准（Excel 导入选 A）

## 目标

1. **服务管理**（独立菜单）：维护全局执行内容目录，不关联项目，无供应商、无汇总。
2. **项目详情 · 执行内容**：从服务目录勾选 → 命名 Sheet → 提交审批 → 审批通过后关联项目；按 Sheet 分 Tab 展示；保留供应商与汇总（仅已通过 Sheet）。
3. 新建审批流：**项目执行内容审批流**（`project_execution_content`）。

## 数据模型

### ExecutionSheet（新建）

| 字段 | 说明 |
|------|------|
| project_id | 所属项目 |
| name | Sheet 名称（用户命名） |
| approval_id | 关联审批单 ID |
| status | 待审核 / 审核中 / 已通过 / 已拒绝 |

### ExecutionItem（调整）

| 字段 | 说明 |
|------|------|
| project_id | **可选**；`null` = 服务管理目录项 |
| sheet_id | 可选；项目内条目归属 Sheet |
| source_item_id | 可选；来自哪条目录项 |

- 目录项：`project_id = null`
- 项目条目：审批提交时从目录**复制**字段，`sheet_id` 绑定批次

## 流程

```
服务管理（目录 CRUD / Excel 导入）
        ↓ 勾选
项目详情 · 服务增项 → 命名 Sheet → 创建 Sheet(待审核) + 复制条目 + 发起审批
        ↓ 审批通过
Sheet → 已通过；项目 Tab 展示；可添加供应商、汇总
        ↓ 拒绝
Sheet → 已拒绝；Tab 显示状态，不可维护供应商
```

## 权限（默认）

| 操作 | 权限 |
|------|------|
| 服务管理 CRUD | 管理员；权限矩阵新增「服务管理」 |
| 项目内提交服务增项 | 项目负责人、项目成员、管理员 |
| 供应商维护 | 已通过 Sheet + 管理员/项目负责人 |

## UI

- 菜单：业务管理下增加 **服务管理** `/services`
- 项目执行内容：Sheet Tab 切换；移除 Excel 导入；服务增项改为目录勾选弹窗

## 审批

- 类型 key：`project_execution_content`，label：项目执行内容
- 工作流编辑器默认模板：**项目执行内容审批流**（项目负责人 → 部门负责人 → 财务）
- `applyApprovalDecision` 通过/拒绝时更新 Sheet 状态

## 兼容

- 历史无 `sheet_id` 的项目条目归入 Tab「历史导入」
