# 供应商付款与项目付款申请融合

**日期:** 2026-09-04  
**状态:** 已批准

## 目标

执行内容「添加供应商」在填写成本金额后，自动发起现有 `project_payment`（付款申请）审批；通过后扣减项目预算并计入已支出；合同/发票可后续编辑补传。

## 行为

1. 保存供应商且金额 > 0 → 自动创建 `project_payment` 审批
2. 金额为空 → 仅登记，不发起审批（`payment_status=无付款`）
3. 审批中/已通过：可编辑合同发票，不可改金额
4. 已拒绝：可改金额并再次保存以重新发起
5. 自跳过自动通过：同步扣预算并标记供应商已通过

## 数据

`SupplierItem` 新增：`approval_id`、`payment_status`（无付款|待审核|审核中|已通过|已拒绝）
