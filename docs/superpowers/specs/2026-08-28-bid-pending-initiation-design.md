# 竞标中标 → 待立项 → 提交立项 设计

日期：2026-08-28  
状态：已批准  
范围：中标自动建关联项目、待立项状态、立项表单、竞标编辑同步。

## 背景

当前 `ensurePendingProject` 在中标后直接创建 **「执行中」** 项目，跳过立项；竞标编辑也不会回写关联项目（如合同金额）。业务期望：中标只建影子项目并进入 **待立项**，由一级负责人或管理员填写立项信息后才变为执行中。

## 目标

1. 竞标标记中标后，项目管理自动出现关联项目，状态为 **待立项**。
2. **一级负责人（项目/竞标负责人）或管理员** 可点击打开立项表单，填写起止时间、二级负责人、成员等后提交 → 状态变为 **执行中**。
3. 竞标管理修改信息时，仅当关联项目为 **待立项** 时同步商务字段。

## 非目标

- 不恢复「立项审批流」（提交立项仍免审批，直接执行中）。
- 不强制迁移所有历史「执行中」项目（可选脚本，实现时单独处理）。
- 不改竞标未中标时的行为。

## 决策摘要

| 项 | 选择 |
|----|------|
| 中标建项状态 | `待立项` |
| 谁可提交立项 | 负责人 + 管理员 |
| 立项后状态 | `执行中`（免审批） |
| 竞标→项目同步 | 仅 `待立项` 时：名称、客户、类型、合同金额←投标金额、结算方式、负责人 |
| 待立项权限 | 不可发起付款/报销等业务；可查看、可立项 |

## 流程

```
竞标.result = 中标
  → ensurePendingProject 创建/跳过已有项目（status=待立项）
  → 通知负责人「请完成立项」

负责人/管理员 打开立项表单 → 提交
  → 更新 start/end、二级负责人(manager)、members、合同编号、预算等
  → status = 执行中
  → 写 ProjectLog + 通知成员

竞标编辑（中标）
  → 若关联项目 status=待立项 → 同步商务字段
  → 若已执行中 → 不同步
```

## 字段映射（竞标 → 待立项项目）

| 竞标 | 项目 |
|------|------|
| project_name | name |
| customer_name | customer |
| project_type | project_type |
| bid_amount | contract_amount |
| payment_method | payment_method |
| manager | manager（一级负责人，立项时可改为二级负责人） |

立项表单额外填写：start_date、end_date、合同编号、budget_cost、二级负责人(manager)、members。

## UI

- 项目管理列表：待立项卡片可点「立项」/整卡进入详情后弹表单。
- 立项弹窗样式对齐现有 InitiateModal（`formStyles`）。
- 待立项项目详情：突出「提交立项」入口；隐藏或禁用执行内容增项、付款等。

## 验收

- [ ] 新建中标竞标 → 项目管理出现待立项关联项目
- [ ] 负责人/管理员可提交立项 → 变为执行中
- [ ] 普通人不可提交立项
- [ ] 待立项时改竞标金额 → 项目合同金额同步
- [ ] 执行中后改竞标金额 → 项目合同金额不同步
